# Java Practice Repository

Welcome to my Java learning journey! This repository is dedicated to daily practice, problem-solving, and building small projects to strengthen my Core Java skills.

## Structure
- `j1/` : Daily coding practice (Problem 1, 2, 3...)
- `j2/` : Intermediate logic and algorithm practice
- `j3/` : Advanced concepts and data structures
- `projects/` : Small applications built to apply learned concepts

## Daily Routine
- **Morning:** Pick one coding problem (e.g., String manipulation, Array logic, Math).
- **Session:** Implement the solution in the corresponding directory (`j1`, `j2`, or `j3`).
- **Review:** Test the code in VS Code, debug, and optimize.
- **Project Work:** Dedicate time each week to build something functional.

## Current Focus
- Core Java fundamentals (OOPs, Exceptions, Collections).
- Algorithm efficiency (Time & Space complexity).
- Clean code practices.
