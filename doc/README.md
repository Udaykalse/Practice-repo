# 🚀 My Coding Practice Lab

Welcome to my learning journey! This repository is a dedicated space where I document my progress, experiments, and projects as I master **Frontend Development** and **Python**.

## 📂 What's Inside?

I have organized my practice into four main pillars:

### 🎨 [HTML & CSS](./html-css)
Focuses on the visual structure of the web.
* **Key Concepts:** Flexbox, CSS Grid, Responsive Design, and Animations.
* **Goal:** Build pixel-perfect, mobile-friendly layouts.

### ⚡ [JavaScript](./javascript)
The logic behind the applications.
* **Key Concepts:** ES6+ Syntax, Promises, Async/Await, and Array Methods.
* **Goal:** Solve algorithmic problems and understand core programming patterns.

### 🌳 [DOM Manipulation](./dom)
Where JS meets HTML.
* **Key Concepts:** Event Listeners, Creating/Deleting Elements, and Form Validation.
* **Goal:** Create interactive and dynamic user experiences without frameworks.

### 🐍 [Python](./python)
General-purpose programming and scripting.
* **Key Concepts:** Data Types, Loops, File Handling, and Scripting.
* **Goal:** Automate tasks and build solid logic foundations.
