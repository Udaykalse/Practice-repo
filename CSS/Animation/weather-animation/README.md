# weather-animation

Pure CSS weather icon animations — no JavaScript, no libraries.

## Scenes

Seven animated weather states displayed side by side in a single strip.

- Sunny — spinning sun rays with glowing orb
- Cloudy — floating white cloud with shadow
- Rainy — grey cloud with falling rain drops
- Rainbow — arcing colour bands with bounce
- Starry — twinkling stars with orbiting moon
- Stormy — dark cloud with flickering lightning bolt
- Snowy — white cloud with drifting snowflakes

## Structure

```
weather-animation/
├── index.html
└── style.css
```

## Usage

Open `index.html` in any modern browser. No build step required.
