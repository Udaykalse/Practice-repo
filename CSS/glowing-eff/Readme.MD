# glowing-flask

A pure CSS 3D animated glowing flask with fluid slosh effect, hue-rotation, and a dynamic drop shadow. No JavaScript. No libraries.

## Preview

A spherical flask filled with glowing cyan fluid that tilts back and forth while the liquid sloshes realistically inside.

## Structure

```
glowing-flask/
├── index.html
└── style.css
```

## Features

- CSS-only animation
- Fluid slosh physics via counter-rotation
- Hue-rotate color cycling
- Specular glint highlight
- Animated ground shadow

## Usage

Open `index.html` in any modern browser.
