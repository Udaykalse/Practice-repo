# 📒 Python Contact Book

A simple **Contact Book** application built using **Python** and **Tkinter**. The application provides an easy-to-use graphical interface for managing contacts, allowing users to add, edit, delete, view, and reset contact information.

---

## 📌 Features

- ➕ Add new contacts
- ✏️ Edit existing contacts
- 🗑️ Delete contacts
- 👀 View selected contact details
- 🔄 Reset input fields
- 📋 Display all contacts in a scrollable list
- ✅ User-friendly GUI built with Tkinter
- ⚠️ Input validation with popup messages

---

## 🛠️ Technologies Used

- Python 3
- Tkinter (GUI Library)

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed

Check your Python version:

```bash
python --version
```

---

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/python-contact-book.git
```

Navigate to the project folder:

```bash
cd python-contact-book
```

Run the application:

```bash
python contact_book.py
```

## 🎯 How to Use

1. Enter a contact name.
2. Enter the phone number.
3. Click **ADD** to save the contact.
4. Select a contact from the list.
5. Click **VIEW** to load its details.
6. Modify the details and click **EDIT** to update.
7. Click **DELETE** to remove a contact.
8. Click **RESET** to clear the input fields.
9. Click **EXIT** to close the application.
