# 🏧 ATM Management System (Python)

A simple command-line ATM Management System built using Python. This project simulates the basic functionality of an Automated Teller Machine (ATM), allowing users to securely log in and perform common banking operations.

## 📌 Features

- 🔐 Secure user login with PIN authentication
- 👤 Multiple user accounts
- 💰 Check account balance
- 💵 Withdraw money
- 💳 Deposit money
- 🔄 Change account PIN
- 📜 View transaction history
- ✅ Input validation and error handling
- 🚪 Safe logout/exit functionality

## 🛠️ Technologies Used

- Python 3
- `getpass` module (for secure PIN input)

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system

### Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/ATM-Management-System.git
```

Navigate to the project folder:

```bash
cd ATM-Management-System
```

Run the application:

```bash
python atm.py
```
